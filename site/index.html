KLEX a small, honest coin

A post-quantum, fair-launch coin, built from scratch.

KLEX is a real proof-of-work blockchain: every transaction is signed with the NIST post-quantum standard ML-DSA, every block is mined with real CPU work, and the genesis block carries one message that can never be changed or bought.

Quickstart

git clone https://github.com/…/klex-coin && cd klex-coin
pip install -r requirements.txt

python -m klex init        # node + genesis (the message is in there)
python -m klex wallet new  # post-quantum keypair → KLEX1… address
python -m klex mine        # earn 50 KLEX per block, real PoW
python -m klex explore     # localhost block explorer
python -m klex verify      # re-validate the whole chain from genesis

What it is not

  • not an investment product — no sale, no presale, no returns promised, ever
  • not a token on someone else's chain — KLEX is its own chain, its own rules
  • not quantum-proof in every layer — signatures are; it is a single small network with small hashrate, and it says so
  • not finished — roadmap: seed node, hardened liboqs signatures, a Rust core

Value starts at zero and stays there until people decide otherwise. That is a feature.

KLEX is issued without sale and runs as an open experiment · MIT license · no names, no promises.
